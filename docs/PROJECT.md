# Project Overview

## Avuno

Avuno is a premium personal media, experience, and memory SaaS. It allows users to meticulously catalogue their life experiences tied to media (movies, TV shows, anime, books, games, music, podcasts).

## Core Identity

Avuno is designed not just as a tracking tool, but as a digital memory vault. The aesthetic is premium, leaning on refined typography, intentional whitespace, and beautiful deep glassmorphism (PremiumGlass).

## Repositories

This is a monorepo containing:

- **Frontend App**: Vite + React
- **Backend App**: NestJS API

## Development Philosophy

- **Strict Typing**: End-to-end TypeScript.
- **Truth First**: Absolute differentiation between user-authored reality (Journal, Memory) and system derivations.
- **Performance**: High performance through TanStack Query, fast APIs, and optimized builds.
