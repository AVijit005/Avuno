# Design System

Avuno uses Design System 2.0 based on OKLCH tokens, implemented via Tailwind CSS and React components.

## Core Concepts

- **OKLCH Colors**: The design system relies heavily on OKLCH for consistent perceptual lightness and vibrant color themes.
- **Hyper-Glass & PremiumGlass**: Specialized UI treatments that provide deep, blurred backgrounds. Premium does not mean excessive effects; it means refined, intentional, and high-quality aesthetic presentation.
- **Typography**: Uses curated modern fonts. Instrument Serif is used for elegant display typography where appropriate.
- **Motion Tokens**: Subtle micro-animations are provided for smooth interactions without overwhelming the user.
- **Accessibility**: Includes reduced motion states and sufficient contrast ratios.

## UI Components

All basic components (Buttons, Inputs, Modals, Dropdowns, etc.) are built using the Radix UI foundation and styled with Tailwind to match the PremiumGlass aesthetics.
