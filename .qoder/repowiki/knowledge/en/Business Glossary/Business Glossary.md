### Chronicle
- Definition：Original product name for the personal media tracking platform, later rebranded to Avuno. Still appears in some legacy code and documentation.
- Aliases：chronicle

### Avuno
- Definition：Current brand name for the personal media tracking platform, replacing Chronicle. Used throughout the landing page and marketing materials.
- Aliases：avuno

### Memory OS
- Definition：Core concept describing the platform's approach to organizing and surfacing personal media memories, including features like Memory Palace, reflections, and timeline views.
- Aliases：memory-operating-system

### Wrapped
- Definition：Year-in-review feature that generates personalized summaries of user's media consumption patterns and achievements.
- Aliases：wrapped-feature

### Memory Palace
- Definition：Interactive visualization feature allowing users to explore their media collection as a spatial memory construct.
- Aliases：memory-palace

### Ten Worlds
- Definition：Categorized sections of the landing page showcasing different aspects of the platform's capabilities and features.
- Aliases：ten-worlds

### Story Chapters
- Definition：Narrative structure used in the landing page to present the platform's value proposition through a cinematic storytelling format.
- Aliases：story-chapters

### PremiumGlass
- Definition：Custom UI component implementing the glass morphism design pattern with living pointer reflection and proximity border effects.
- Aliases：premium-glass

### Landing v2
- Definition：Second iteration of the marketing landing page with improved cinematic narrative arc and conversion-focused design.
- Aliases：landing-v2、new-landing
