The root is a Vite + TanStack Start application whose entry points are declared in vite.config.ts (server entry → src/server.ts, route file ignore for analytics-page) and served through Bun via bunfig.toml. Child modules are integrated as follows: the frontend_app provides the React/TanStack Router SPA; tests supplies Playwright e2e flows, Vitest unit tests, and a Python visual-regression harness invoked through npm scripts; docs holds reference material consumed by the project's README and DEPLOYMENT-GUIDE; public_assets feeds static files (manifest, icons, robots.txt, sitemap.xml) to Vite/PWA; dev_scripts are one-off Node/PowerShell/Docker utilities invoked directly from the workspace root. Cross-cutting concerns shared by all children include TypeScript path aliasing (@/* → ./src/*), ESLint + Prettier configuration, and the Bun minimumReleaseAge supply-chain guard.
