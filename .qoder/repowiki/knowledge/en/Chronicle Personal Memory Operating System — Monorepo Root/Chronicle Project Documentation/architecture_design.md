This module is a flat collection of Markdown reference documents describing both the frontend (TanStack Start/React) and backend (NestJS/Prisma/BullMQ) halves of the Chronicle application. Each file targets a distinct operational concern: README.md documents the overall app architecture and folder layout; DESIGN-SYSTEM.md codifies visual/motion tokens; PRODUCTION.md and DEPLOYMENT.md describe the Docker-based stack (PostgreSQL, Redis, MinIO/S3, BullMQ workers); SECURITY.md enumerates auth, authorization, and transport protections; RUNBOOK.md provides incident-response steps; OPERATIONS.md and BACKUP.md cover day-2 tasks; DISASTER_RECOVERY.md covers restore procedures. There is no executable code — the files cross-reference source paths under `src/` and `docker-compose.*.yml` as authoritative sources of truth.
