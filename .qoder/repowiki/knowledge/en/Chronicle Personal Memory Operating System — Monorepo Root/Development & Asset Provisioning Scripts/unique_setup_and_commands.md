Scripts assume a Windows path layout rooted at `C:\chronicle-your-media-story-mainzipzip\` and a Gemini antigravity CLI session under `C:\Users\palav\.gemini\antigravity-cli\brain`. Video downloaders require `yt-dlp.exe` in the repo root. The E2E stack is started via `docker compose -f docker-compose.e2e.yml up`, which builds the backend, runs Prisma migrations, starts the Bun dev server on port 5173, and executes Playwright tests against it.
