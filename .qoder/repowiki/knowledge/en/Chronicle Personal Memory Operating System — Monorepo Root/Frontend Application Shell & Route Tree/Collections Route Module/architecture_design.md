Three TanStack Router file-based route files under `src/routes/` define the `/app/collections` namespace:
- `app.collections.tsx` is a layout route that renders only an `<Outlet />`, acting as a parent shell.
- `app.collections.index.tsx` implements the `/app/collections/` index, fetching all collections via the `useCollections` hook, adapting responses with `adaptCollectionResponse`, then composing multiple section components (`FeaturedCollections`, `EditorialGrid`, `MemoryCapsule`, `SmartCollectionCard`, `DiscoveryCollections`, `RelatedJourney`) inside `RevealSection` wrappers, plus a floating `CreateCollectionFab` and modal.
- `app.collections.$id.tsx` implements the dynamic `/app/collections/$id` detail route, loading a single collection via `useCollection(id)`, deriving a hero with accent colors from `useArtworkAccent`, rendering a view-mode toolbar (editorial/list/compact), a searchable grid of items, and a series of chaptered sections (`CollectionStory`, `CollectionTimeline`, `CollectionConnections`, `CollectionInsights`, `CollectionExplorer`, `CollectionWorkspace`, `CollectionHeatmap`, `CollectionFingerprint`, `CollectionMoodboard`, `CollectionChapters`, `SmartCollectionSuggestions`, `CollectionAchievements`, `CollectionJournal`, `CollectionDiscussions`, `CollectionAnalyticsPreview`, `CompanionCollections`, `CuratorNotes`, `CollectionFooter`).

Data flows through shared hooks in `@/hooks/use-collections` and response adapters in `@/lib/adapters/collection`, keeping routes thin presentational shells over reusable UI components.
