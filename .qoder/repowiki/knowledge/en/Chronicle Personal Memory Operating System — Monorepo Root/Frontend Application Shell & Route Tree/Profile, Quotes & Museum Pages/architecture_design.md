Three TanStack React Router route files under `src/routes/`, each exporting a `Route` created via `createFileRoute` for `/app/profile`, `/app/quotes`, and `/app/museum`. Each route is a presentational component that composes domain-specific sub-components from `@/components/profile/*` (IdentityHero, MediaDNA, MemoryMap, LifeChapters, MemoryCapsules, Museum, QuoteGallery, BookmarkPanel, SaveForLaterPanel, UniversalNotes, EditorialProfileFooter) and editorial layout primitives from `@/components/editorial/*` (PullQuote, SplitBlock, Collage). Data fetching is delegated to hooks in `@/hooks/*` (`useOverview`, `useStreaks`, `useCollections`, `useLibrary`) with raw responses adapted through `@/lib/adapters/*` before being passed down as props. The profile page acts as an aggregator orchestrating all sections, while the quotes and museum pages are thin shells around their respective feature components.
