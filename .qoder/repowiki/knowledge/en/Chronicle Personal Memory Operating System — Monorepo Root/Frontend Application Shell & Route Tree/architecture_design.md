The app is organized as TanStack Router's file-based routing under `src/routes/`, with a single entry point in `router.tsx` that creates the router from `routeTree.gen.ts` (auto-generated by TanStack Router). The root route (`__root.tsx`) sets up the HTML shell, injects global CSS/fonts, applies dark/light theme via document class toggling, restores the user session by calling `authApi.getCurrentUser()` when an access token exists, and wraps everything in `QueryClientProvider` + `ErrorBoundary` + `Suspense`. The `/app` route acts as the authenticated layout: its `beforeLoad` guard checks for a stored access token and redirects to `/auth` if missing, then pre-fetches the current user into React Query before rendering `AppShell` (which provides sidebar/topbar/mobile nav) around child outlets. All feature modules — library, collections, profile_and_identity, auth_flow, landing_pages — are simply sibling files under `routes/` that compose reusable components from `components/` and data hooks from `hooks/` and `lib/`. Cross-cutting concerns (analytics page tracking, error reporting via `lovable-error-reporting`, query key definitions, API client) are centralized in `lib/` and consumed uniformly by every route.
