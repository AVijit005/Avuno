Three TanStack React Router file-based route components under `src/routes/`, each exporting a `Route` created via `createFileRoute` with a path matching the filename (`/auth/callback`, `/auth/forgot-password`, `/app/onboarding`). The callback route is stateless: it reads `code` or `token` from `window.location.search`, exchanges the code for an access token via `apiPost('/auth/exchange', ...)`, stores it through `setAccessToken`, then redirects to `/app`. The forgot-password page is a controlled form component backed by local `useState` (currently stubbed with a `setTimeout` since the backend endpoint does not exist yet). The onboarding page is a two-step wizard driven by local state (`step`, `selected` media types), persisting choices to `localStorage` keys `chronicle_onboarding_complete` and `chronicle_media_types` before navigating to `/app`. All pages share visual composition through shared UI primitives (`AtmosphereBackground`, `LiquidGlassCard`, `PremiumGlass`, `PremiumButton`) and report analytics via a centralized `analytics` module.
