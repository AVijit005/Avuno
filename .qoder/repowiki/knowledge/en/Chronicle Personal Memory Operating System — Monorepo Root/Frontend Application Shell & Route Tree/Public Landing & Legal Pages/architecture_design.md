Each route is a single-file TanStack Router module created via `createFileRoute`, mapping a URL path to a React component. The new-landing page delegates rendering to a reusable `NewLandingPage` component from `@/components/landing-v2`, while pricing, terms, and privacy are self-contained inline components. SEO metadata (title, description) is declared through the router's `head` option on the landing route. Navigation between pages uses TanStack Router's `useNavigate` hook or `<Link>` components, and user interactions (e.g., upgrade click) are tracked through a shared `@/lib/analytics` module. All pages share a consistent dark oklch background theme and Tailwind utility classes.
