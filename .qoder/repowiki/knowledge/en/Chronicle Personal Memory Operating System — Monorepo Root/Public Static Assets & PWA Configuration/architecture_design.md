Flat public directory consumed directly by the Vite dev server and production build. The root-level files define the PWA identity (manifest.webmanifest with standalone display and dark theme colors #0d0d14, paired with icon-192.png/icon-512.png and icon.svg) and SEO metadata (robots.txt disallowing /app/, sitemap.xml pointing to chronicle.app). The landing/ subdirectory holds all marketing visuals organized by purpose: images/ contains background textures, chapter illustrations, polaroid mockups, poster frames, timeline thumbnails, and world-category icons; videos/ is reserved for landing-page video assets. The _redirects file documents that API traffic bypasses the frontend and routes straight to the backend via the VITE_API_URL environment variable, establishing a clear separation between static asset serving and API proxying.
