### NestJS Backend Framework
- **Role**: Production backend API framework built on Express
- **Architecture**: Modular structure with controllers, services, guards, decorators, and repositories
- **Runtime**: Node.js 22+ with TypeScript compilation
- **Development**: CLI tools for scaffolding, testing, and debugging
- **Production**: Separate build process generating optimized JavaScript output
